# DianiConnect

Mobile-first, trust-first local services marketplace for Kenya’s South Coast.

## Stack
- Astro
- TypeScript
- Cloudflare Pages
- Supabase

## Core Goal
Help users find and book trusted local services fast.

## v1 Focus
- Provider discovery
- Booking requests
- Provider onboarding
- Admin moderation

## Notes
- Built for free-tier infrastructure
- Mobile-first
- Performance-first
