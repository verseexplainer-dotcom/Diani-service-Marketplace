# BRAND

## Overview
DianiConnect should feel calm, trustworthy, and practical for people booking local services on Kenya’s South Coast.

The visual language is clean and editorial:
- mostly white canvas
- generous spacing
- one primary action color used sparingly
- rounded, touch-friendly controls
- simple, human copy

This is a local-services brand, not a finance product.

## Core Voice
- local
- clear
- human
- practical

Use:
- "Find trusted help near you"
- "Book a service quickly"
- "Verified local providers"

Avoid:
- hype language
- corporate jargon
- claims like "revolutionary" or "seamless ecosystem"
- any finance/trading terminology

## Color System

### Brand & Action
- **Ocean Blue** `#0052FF` — primary CTA/button/link accent (use sparingly)
- **Ocean Blue Active** `#003ECC` — pressed state
- **Ocean Blue Disabled** `#A8B8CC` — disabled state
- **Coral CTA Accent** `#FF6B57` — optional highlight for selected conversion moments only

### Surface
- **Canvas** `#FFFFFF`
- **Surface Soft** `#F7F7F7`
- **Surface Strong** `#EEF0F3`
- **Surface Dark** `#0A0B0D`
- **Surface Dark Elevated** `#16181C`

### Text
- **Ink** `#0A0B0D`
- **Body** `#5B616E`
- **Muted** `#7C828A`
- **On Primary** `#FFFFFF`
- **On Dark** `#FFFFFF`

### Semantics (status only)
- **Success** `#05B169` (text/icon only)
- **Error** `#CF202F` (text/icon only)

## Typography
Use practical, readable web-safe stacks:
- Headings: `Inter, system-ui, sans-serif` (400/600)
- Body/UI: `Inter, system-ui, sans-serif` (400/500/600)
- Numeric data: `JetBrains Mono, ui-monospace, monospace`

Rules:
- keep headline weight moderate (avoid ultra-bold hero text)
- keep body at 16px baseline for readability
- keep number-heavy rows monospaced for alignment

## Layout & Spacing
- base spacing unit: 4px
- major section rhythm: 96px vertical spacing
- max content width: ~1200px centered
- mobile-first: design 1-column first, then scale to tablet/desktop

## Shape Language
- buttons/badges/search: pill radius (100px)
- cards/sheets: 24px radius
- inputs: 12px radius
- icons/avatars: full circle
- avoid sharp corners on primary interactive elements

## Signature Components
- **Dark hero band** with simple layered UI cards
- **Provider cards** with clear CTA and trust signals
- **Category chips** in pill shapes for quick browsing
- **Booking CTA band** near page bottom with one strong primary action

## Do / Don’t
### Do
- keep blue sparse so CTA intent stays obvious
- prioritize trust copy: verified, local, clear pricing, response time
- keep interactions lightweight and fast on mobile
- use compressed images and minimal JS

### Don’t
- don’t turn pages into dashboard-like dense UIs
- don’t use multiple competing accent colors for actions
- don’t introduce finance, trading, or exchange language
- don’t overload pages with animations or heavy media

## Responsive Rules
- Mobile: single-column cards, stacked booking details, sticky bottom CTA when useful
- Tablet: 2-column feature grids where appropriate
- Desktop: up to 3-column listing grids; preserve generous whitespace
- minimum tap target: 44px height for primary actions

## Content Intent by Section
- Hero: fast clarity on service discovery + trust
- Categories: help users scan quickly
- Provider blocks: proof (rating, reviews, service area)
- Booking flow: short, low-friction steps
- Footer/CTA: one clear next action
